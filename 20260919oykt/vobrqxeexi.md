# 丁克10年，我意外怀孕后，娘家嫂子不高兴，亲侄女儿把我家门砸了

> 更新时间：2026-09-19 (UTC+8)

0 1

22岁的亲侄女儿把我家的门砸了！

她突入其来的那一砖头，不仅敲碎了我的心，还差点儿敲断了我们估侄间数十年的血脉亲情。

那是一个闷热的中午，我一个人在家，吃过午饭后躺在客厅的沙发上小憩。

我正要迷迷糊糊地睡着时，门口突然传来“砰！砰！砰！”三声巨响，吓得我全身一颤，立马醒了神。

我赶紧跑去门口，门口却没了动静，看着紧闭的门我有些紧张，这大白天的难道还有歹徒不成？

我没有立刻开门，悄悄地透过门上的猫眼察看门外的情况，这不看不知道，一看吓一跳，我的侄女小菲正怒气冲冲地站在门口，手里还拿着半块红砖头。

我心里一咯噔，小菲这是怎么了？谁又惹到她了？

好在不是歹徒，我拍拍胸口舒了一口气，把门打开后，才发现我家门锁的位置已经严重变了形。

想起刚才那三声巨响，我的火气一下上来，指着变形的门对小菲质问道：“这是你砸的？”

小菲昂起头瞪着我，承认得很干脆：“没错！是我砸的！”

我有些错愕，很不理解她的行为：“为什么要砸我家的门？姑姑哪里得罪你了？”

小菲指着我的肚子，气冲冲道：“我妈说，你怀孕了？”

我摸摸自己的小腹，喜不自禁地冲小菲轻轻一笑：“是啊，你很快就要当大姐姐了！”

小菲听了这话，脸上不仅没有一丝欢喜，还冷冷一哼，说出来的话更是差点惊掉我的下巴，直戳我的心窝子：“小姑，你和我姑父不是丁克吗？怎么突然又要孩子了？你都四十岁了，高龄产子，你不怕胎死腹中下不来手术台吗？”

小菲是我抱大的孩子，我真没想到小菲会说出这番恶毒的话来，我压住一团心火，对小菲问道：“你这什么意思？小姑平日里待你不薄吧？你先是来砸我家的门，现在又咒骂我和我的孩子，你这胆子真是越来越大了，我看都是我们平时把你宠坏了是不是？”

小菲气得咬牙切齿，红着眼圈盯着我，愤愤不平道：“谁让你说话不算数！你曾经说过的，你这一辈子都不会生小孩，只要我肯给你养老，你的财产都会留给我！而现在，你却怀孕了，你的孩子一出生，那我岂不是什么都没有了！”

0 2

小菲的话再次刺痛了我的心，我几乎不敢置信这话是从她嘴里说出来的，原来，她是为了我的财产而来！年纪轻轻就这么懂得算计了！她的背后肯定有推手，不用怀疑，那个人就是我嫂子，那是一个见钱眼开的女人！

我瞠目结舌地看着小菲，对她十分失望，缓了缓问道：“是你妈让你来的对不对？”

小菲的眼里闪过一丝慌张，咬紧唇角不肯承认道：“不关我妈/的事！是我自己要来的！我就想问你一句话，你还认不认我这个侄女儿！”

我耐着性子点点头说道：“你是我哥的女儿，我当然认你这个侄女，这是永远割不掉的血脉亲情。别站在门口了，有什么话进屋说吧，不要让邻居看笑话。”

我说着去拉小菲的手，小菲却不领情，一把甩开了我，鼓着脸，心口起伏不定道：“你既认我，就要兑现你当初的承诺，我不希望你的孩子来到这个世上跟我争财产！”

我心里猛地涌起一股寒流，盯紧小菲的眼睛，失望透顶道：“小菲，你何时变得这般现实和残忍了？我也没想到我会怀孕，这是一个意外，孩子既然来了，就是缘分，无论如何我都会把他生下来的。还有，我并没有承诺过你什么，一直以来，不过是你妈妈在煽风点火而已。她把你教坏了，你知道吗？”

小菲听不进我的话，脚下一跺，冲我吼道：“不许你说我妈！你如果坚持要把这个孩子生下来，你就不是我姑！我要和你断亲！”

“断亲？”我的脑袋里翁地一声响，这就是我从小疼到大的亲侄女，为了争财产居然要和我断亲，我又想笑又好气，淡淡道，“既如此，那你走吧，你太让我失望了，我也不想再看见你！回去转告你妈妈一句话，这个世上，钱不是最重要的！”

小菲听后，将手里的砖头一扔，头也不回地走了。

我望着小菲绝决的背影，心里好一阵酸楚，再回头看着眼前变了形的门，不禁轻轻一叹，捡起那半块砖头默默地回了屋。

我靠在沙发上，回想着小菲刚才说的那些狠话，越想越难受。

0 3

我叫林兰，今年刚刚四十岁。

我结婚较晚，三十岁才嫁给我的老公李波。

我和李波起初都在外企工作，我们是在一场酒会上认识的，当时我们互相欣赏，有说不完的话，既是相见恨晚，也是一见钟情。

后来，因为业务上的往来，我和李波日渐熟悉，很自然地成了男女朋友。

再后来，我们双双离职，合伙开了一家公司。

公司进入正轨后，李波向我求了婚，我很高兴地答应了。

我和李波都是事业心比较强的人，我们嫌生孩子麻烦，所以结婚前我们就约定好不要小孩，打算做一辈子的丁克。

这样，我们不仅可以安心搞事业，还能过潇洒自由的二人世界。

当我们把这个决定告诉双方父母后，遭到强烈反对，但是我和李波态度坚决，家里人拿我们也没办法。

李波家境比我好，他有一个弟弟，比他结婚早，孩子有两个，一儿一女。

我有一个哥哥，比我大8岁，为人憨厚老实，却娶了一个王熙凤一样精明的老婆。

小菲是我哥的独女，从小娇生惯养，调皮捣蛋。

小菲出生的那一年，我才18岁，对于这个小侄女，我是非常疼爱她的，对她几乎是有求必应。

哥哥嫂子的文化都不高，开了一家小饭馆，经济条件勉强过得去。

我大学毕业后，顺利进入了一家外贸公司，工资尚可，我每个月发了工资除了孝敬父母外，还经常给我哥哥嫂子买礼物，小侄女平时穿的衣服鞋子和学习用品几乎被我全包。

在我父母和我哥的眼里，我是听话懂事，孝顺体贴的乖乖女。

在我嫂子眼里，我的钱就像大风刮来的，不花白不花。

在我侄女儿眼里，我是她的百宝箱，她要什么，我就能变出什么。 

兴许是我对他们太好了，日积月累下来，我所做的一切全都成了理所当然，要是哪天没做到位，就是我的不是。

我父母和哥哥倒没什么，主要是我那个嫂子，总是盯着我的钱包。

0 4

比如我因为工作忙，忘记给小侄女买换季的衣服，嫂子就会提醒我：“小兰，你侄女儿没衣服穿了，你什么时候给她买啊？”

我顾不上去买，就对嫂子说：“我现在没时间，你先带小菲去买两件，后面我再给她补上。”

嫂子却大言不惭地来了一句：“你也不用补了，把买衣服的钱转给我就行了。”

我虽有些不悦，但也不想因为这几百块钱和嫂子闹得不愉快，何况那是我的亲侄女，我不疼她谁疼她呢？就把钱转给嫂子了。

我和李波合伙开公司后，嫂子眼红，找我借些钱给她，她想把饭店扩大。

我问嫂子要借多少？

嫂子笑着伸出两根手指让我猜，我问：“两万吗？”

嫂子摇摇头说道：“两万哪够啊，二十万！”

我微微一怔，我和李波为成立新公司已投资不少，手上也没多少钱，嫂子开口就要20万，实在让我为难，好声好气地对她说道：“嫂子，我现在没有20万，你若真着急的话，我最多能借你五万。”

嫂子听后立马沉下脸来，满脸不屑地盯着我：“你打发叫花子呢！你和李波开那么大的公司，20万都拿不出来，谁信啊！”

我耐着性子跟嫂子解释，嫂子却不愿听，转头就走了，跑到我妈跟前告我的状，说我有了男人就不顾姊妹情分了。

我听得委屈极了，李波知道此事后，安慰我说，都是一家人，能帮就帮一把吧。

没两天，我和李波凑齐十万块送到嫂子面前说：“嫂子，这十万块我们尽力了，20万我们真的没有。”

当着李波的面，嫂子也不好甩脸子，装模作样地牵住我的手说道：“小兰，嫂子就知道你不会不管我们的，十万就十万吧。前两天是我冲动了，不该那样对你。你也知道，你哥是一个闷葫芦，这家里家外都得靠嫂子张罗，你得理解嫂子，我把饭店扩大，还不是为了家里好过啊！”

我松开嫂子的手，一笑而过，没有说话。

这十万块钱，我比谁都清楚，给出去了，是肯定要不回来了。

而事实确实如此，嫂子至今都没有把那十万块还给我们。

05

我嫁给李波后，我们一边享受二人世界，一边努力经营公司，日子过得顺风顺水。

我嫂子不相信我和李波不生孩子，总是三番五次地悄悄问我：“小兰，你们公司越做越大，肯定赚了不少钱吧？你们真不打算要孩子？”

我漫不经心道：“也没赚多少，孩子的事还和以前一样，不打算要。”

嫂子的眼睛滴溜溜一转，对我试探道：“那你们赚这么钱干嘛呀，就你们两个也花不完啊！”

我正欲接话，嫂子话音一转，猛地一拍我的肩膀冲我笑道：“你们这些受过高等教育的人，思想跟我们就是不一样！其实想想，人活着也不一定非得要生孩子！嫂子支持你！而且你别担心以后老了没人管你，你那么疼小菲，她是你的亲侄女，以后不会不管你的！咱们是一家人嘛！不分彼此对不对？”

我听出了嫂子的意思，对她淡淡一笑：“小菲是我的亲侄女没错，但是我不想给她添任何麻烦，我和李波都商量好了，等我们老了以后就到处旅游，实在走不动了就进养老院。”

嫂子嘴角一撇：“你这话说得多生分啊！怎么叫麻烦呢？而且，那养老院可不是人待的地方。还有啊，这男人再好，也不能百分百地信任他，你得提前给自己铺好后路，特别是家里的财政大权，一定要握在自己手里，不要到时候，男人没了，钱也没了。”

嫂子越说越来劲儿，我不想听下去，故意打断了她的话：“嫂子，谢谢你提醒，我心里有数。”

嫂子笑弯了眼睛，话里有话道：“那就好，你要永远记住，只有血亲才是最真实的，你对小菲好，她定不会辜负你的期望。”

我笑笑没有作声。

不久后，小菲就跑到我跟前问我：“小姑，我妈妈说只要我以后给你养老，你赚的钱就全是我的，这是真的吗？”

我惊讶于一个孩子问出这样的话，更怨嫂子教坏了小菲。

我没有回答小菲的问题，让她不要想大人这些事情，好好读书。

但我没想到，这个事情会在小菲的心里根深蒂固。

0 6

小菲因为缺少父母的管教，平时很贪玩，成绩也不是很好，后来考了一个一般的大学。

大学毕业后，嫂子就把小菲交给了我，让我在公司给小菲安排个职位。

这不是一件难事，我直接就答应了，暂且安排了一个较轻松的职位给小菲。

哪知这小菲不争气，不仅无心工作，还仗着我是她小姑，每天都一副高高在上，颐指气使的样子，把公司的气氛搅得一团遭。

我一气之下，就把小菲开除了。

为了这事，小菲骂我六亲不认，嫂子也说我冷血无情。

我真是被这对母女气得心口疼，加上那段时间工作太累，我一时没撑住，生了一场病。

住院期间，小菲和嫂子都没来看我，就我爸妈提着牛奶和水果来看了我一眼。

我爸妈临走时，只见我妈愁眉苦脸，一副欲言又止的样子。

我忍不住对我妈问道：“妈，你怎么了？你是不是有什么话要跟我说呀？”

我妈正待开口，我爸突然拉住我妈的手发气道：“说什么说，回家！”

我越看越不对劲儿，叫道：“爸妈，到底啥事儿啊，坐下来好好说。”

我妈挣脱我爸的手，重新回到我的病床前坐下，犹豫了半天，才难为情地对我说道：“小兰，你这次突然病倒，我们都很担心你，幸好不是什么大病。你身边无儿无女，要是有个三长两短，你赚那么多钱不都便宜李波了吗？你得替我们考虑考虑啊，毕竟我们才是一家人啊！”

我妈磕磕巴巴拐弯抹角地说了这几句话，我听明白了其中的意思，压制住心头的火，对我妈问道：“妈，你是什么样的人，我再清楚不过了，这话不是你的心里话吧？如果我没猜错的话，是嫂子怂恿你这么说的吧？她是想钱想疯了吗？我才四十岁，她就想觊觎我的财产了吗？”

我妈低着头不吭声，我爸一声长叹，对我安慰道：“闺女，你别往心里去，你嫂子那个人，就是那个样，不用理她！这么多年，你为咱家为你哥哥嫂子和小菲，付出得已经够多了，以后不要再付出了，好好养自己的身体。爸还是想劝劝你，趁着还能生，赶紧给自己生一个孩子吧！”

我爸说完就拉着我妈走了，我转头看向窗外，灰蒙蒙的像要下雨。

07

我和李波已经丁克近十年，早已习惯两个人的生活，若是生个孩子出来，我不知道如何去迎接这个小生命。而且那样的话，必定会打乱我们的生活，我也不得不放下我热爱的事业。

想到这里，我心里既纠结又恐惧。

然而，一切逃不过命运，该来的还是来了。

出院不到两个月，我就意外怀孕了。

看着那报告单，我整个人懵了，当我战战兢兢地把这个坏消息告诉李波时，李波也沉默了。

当天晚上，我们夫妻俩认真考虑后，决定把孩子生下来，坦然地接受孩子的到来。

双方家庭得知我怀孕的消息后，除了我嫂子，没人不开心。

大家都在庆贺我时，嫂子却在我面前泼冷水：“你都这么大年纪了，还生孩子干嘛？高龄产妇风险很大的，你不要命了吗？”

我懒得理会嫂子，没有搭话，气得她脸色发白，一双眉毛都快挑上天了。

自打怀孕后，我就放下了工作，安心在家养胎。

没想到，刚旅游回来的小菲听闻我怀孕的消息后，在嫂子的指使下，竟然拿着砖头来砸了我的门。

要不是看在她是我亲侄女的份上，我真想报警把她抓进局子里去。

当天晚上老公下班回来看到那变形的门后，问我怎么回事，我一五一十地告诉了他。

老公气得立马打电话给我哥，我哥不知道这事，当晚就带着嫂子和小菲到我家里来向我陪礼道歉。

我哥平日里一般不发火，发起火来，嫂子也是怕他的，加上这件事确实是嫂子和小菲做得太过分。

嫂子当面承认了是她指使小菲来找我麻烦的，还给我道了歉。

我卖了我哥一个面子，原谅了嫂子和小菲，不管她们是不是诚心道歉，我都懒得理她们，借故身体有些累，就回房间了。

这件事后，嫂子和小菲再也没有找过我的麻烦，我也几乎不回娘家了，偶尔给父母打个电话。

这次，我算是彻底想明白了，我对小菲再好，她始终是大哥大嫂的孩子，在她眼里，我这个姑没有我的财产重要。

天幸，我现在有了自己的孩子。

以后，就安安心心地过自己的小日子吧，娘家的事少掺和。
